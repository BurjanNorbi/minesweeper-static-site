# Reszponzív, szemantikusan felépített HTML5 alapú weboldal

Ez a projekt egy **statikus HTML weboldal**, amely a modern webfejlesztési szabványokat követi, különös figyelemmel a **reszponzivitásra**, a **hozzáférhetőségre**, a **HTML5 szemantikus tagek használatára**, valamint a **WCAG 2.0** irányelvekre. Az oldal célja egy minta webhely bemutatása, amely megfelel az oktatási projekt során megadott minden formai és technikai követelménynek.
